# Testing Elements

This project contains small React components created as a playground for experimenting with testing patterns using Jest and React Testing Library. It focuses on unit tests, snapshot tests, mocks, spies, and strategies for testing ESM modules in a Next.js + TypeScript environment.

Run the test suite with:

```bash
npx jest
```

That's it — use the `src/components` and `src/utils` folders to explore examples and tests.
